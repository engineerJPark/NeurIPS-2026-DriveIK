Grounding Driving VLA
via Inverse Kinematics

Junsung Park, Hyunjung Shim
KAIST
NeurIPS 2026
Paper Video BibTeX

Abstract

Counterfactual obstacle insertion exposes blind planning in representative Driving VLAs: their trajectories remain largely unchanged despite a vehicle appearing directly ahead. An empirically calibrated bias–variance analysis identifies how ego-predictable training examples admit a shortcut through ego status and commands. We address this failure with an inverse-kinematics-inspired architecture that anchors trajectory decoding on current and predicted future visual states. First, a next visual state prediction objective that requires the LLM to predict the future visual scene provides dense visual supervision and suppresses shortcut paths. Second, a separate Inverse Kinematics Network (a cross-attention-based conditional diffusion model) that takes only the current and future visual states as input is designed to suppress reliance on ego status and textual shortcuts during trajectory decoding. Our 0.5B model achieves state-of-the-art trajectory planning performance on NAVSIM-v1, NAVSIM-v2, and nuScenes using cameras alone, without LiDAR or a BEV encoder. Against the matched OpenDriveVLA* baseline, it improves NAVSIM PDMS and EPDMS by 19.0 and 20.4 points, respectively. Controlled ablations and intervention analyses support improved use of visual features, with additional benefits from future-state prediction in dynamic situations such as turning.

Key Contributions

  • ⏩ Diagnosing blind planning. Controlled visual interventions reveal that representative Driving VLAs can retain nearly identical trajectories after an obstacle is inserted. A bias–variance analysis characterizes the ego-status shortcut under an empirically calibrated majority-regime assumption.
  • ⏩ Grounding actions in visual states. Next visual state prediction provides dense visual supervision. An Inverse Kinematics Network decodes trajectories from only the current and predicted future visual states, removing direct ego-status and command inputs from the trajectory decoder.
  • ⏩ Strong performance with a 0.5B backbone. Using three front cameras, our model achieves 92.2 PDMS on NAVSIM-v1, 90.6 EPDMS on NAVSIM-v2, and 0.06 m average L2 error on nuScenes under the ST-P3 evaluation protocol.

Overall Methods

Ego status and route commands guide future-state prediction through the LLM, while the trajectory decoder has no direct access to them. The IK Network is a cross-attention conditional diffusion model, with trajectory-loss gradients stopped at its visual conditioning inputs.

“Inverse kinematics” describes the idea of inferring a trajectory between a start and a target visual state; it is an architectural analogy rather than a strict vehicle-dynamics formulation.
